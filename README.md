# 사단 통합 톡 (PWA)

A·B사단 시트에 쌓이는 지시와 보고를 카카오톡 같은 화면에서 읽고, 입력창에서 보낸 지시를 해당 탭의 마지막 행에 기록하는 웹앱입니다.
이 저장소는 **화면(프론트엔드)만** 담고 있습니다. 시트를 읽고 쓰는 서버는 Google Apps Script 웹앱이며, 앱의 ⚙️ 설정에서 웹앱 URL과 공유 토큰을 넣어 연결합니다.

## 쓰는 법

1. https://leh556-dot.github.io/sadan-talk-pwa/ 를 엽니다.
2. 오른쪽 위 ⚙️(설정)에서 **Apps Script 웹앱 URL**(`.../exec`)과 **공유 토큰**을 넣고 저장합니다.
3. 홈 화면에 추가하면 앱처럼 열립니다(설치형 PWA).

- 토큰과 설정은 **그 브라우저(localStorage)에만** 저장되고 이 저장소나 페이지에는 들어 있지 않습니다.
- 설정 전에는 내장 **데모 모드**로 가짜 샘플 대화가 보입니다. 데모 데이터는 실제 시트 내용이 아닙니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 |
| `styles.css` | 카톡 스타일 UI (폰·태블릿·PC 반응형) |
| `app.js` | 방·말풍선·필터·검색·전송·설정 |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 서비스 워커(앱 셸 캐시) |
| `demo/snapshot.js` | 데모용 가짜 샘플 데이터 |
| `icons/` | 앱 아이콘 |

## 기능

- 방 5개: 전체 통합방 / B사단 방 / A사단 방 / AI 채팅방 / **🏢 사단 오피스**
- **🏢 사단 오피스**: 사장방·팀장실·A·B사단 자리를 2D 오피스로 보여 줍니다. 각 대원의 마지막 시트 기록으로 30분 안 = 🔥 열일중, 2시간 안 = 💻 작업함, 그 밖 = ☕ 대기/💤 휴식 상태를 표시하고, 캐릭터를 누르면 최근 기록을 보여 줍니다. 명단에 없는 새 작성자는 그 사단에, 탭만 있고 아직 글 없는 이름은 `새로 합류` 구역에 자리가 자동으로 생깁니다.
- 필터(전체·지시·보고·미완료), 대화 검색, 자동 새로고침
- 입력창에서 대상 시트·탭과 태그를 골라 지시 기록
- `+` 첨부: 사진·동영상·파일을 Google Drive에 올리고 링크를 시트에 기록

데모 모드에서는 오피스가 항상 살아 있어 보이도록 샘플 행의 시각을 페이지를 열 때 ”지금” 기준으로 옮깁니다(가짜 샘플에만 적용).
