# 사단 통합 톡 — A·B사단 시트 연동 카톡형 웹앱(PWA)

A사단(`Instinct 요청함`)·B사단(`B사단 요청함`) 시트에 쌓이는 **지시와 보고를 카카오톡처럼 한 화면에서** 읽고,
아래 입력창에서 보낸 지시를 **해당 탭의 마지막 행에 바로 기록**하는 웹앱입니다.
폰·태블릿·PC 브라우저에서 같은 파일로 동작하고, 홈 화면에 설치(PWA)할 수 있습니다.

- 서버·유료 호스팅 없이 **Google Apps Script만으로** 배포할 수 있습니다.
- Apps Script 주소를 넣기 전에도 **데모 모드**로 실제 시트에서 가져온 최근 기록을 그대로 눌러볼 수 있습니다.

## 3. 바로 써보기 (데모 모드)

1. 이 폴더에서 정적 서버를 하나 띄웁니다.
   ```bash
   cd division-chat-pwa
   python3 -m http.server 8765
   ```
2. 브라우저에서 `http://localhost:8765/` 를 엽니다. (폰이면 PC와 같은 와이파이에서 `http://<PC IP>:8765`)
3. 처음 열면 **데모 모드**입니다. 실제 A·B사단 시트에서 읽은 최근 기록이 말풍선으로 보입니다.
   - 왼쪽(폰은 첫 화면)에서 `전체 통합방` / `B사단 방` / `A사단 방` / `AI 채팅방` / `🏢 사단 오피스` 전환
   - 상단 `전체 · 지시 · 보고 · 미완료` 필터, 돋보기(대화 검색), `⋯`(방 메뉴: 탭 선택·자동 새로고침)
   - 아래 입력창의 `B사단 · 시트1` 칩을 눌러 **기록할 시트/탭** 선택(A사단 123개 탭 전부 검색 가능), `@전체` 칩으로 대상 태그 선택(`태그 없음`을 고르면 제목이 `[지시]`만 들어갑니다)
   - **데모 모드에서는 전송해도 실제 시트에 쓰지 않고 화면에만 표시**됩니다(안내 문구 표시).

> 파일을 더블클릭(`file://`)해도 데모는 열리지만, 서비스 워커·설치형 앱은 http(s)에서만 동작합니다.

## 4. 실제 시트와 연결하기 (배포 2가지)

### 방법 A — Apps Script 단독 배포 (서버·호스팅 불필요, 가장 간단)

1. <https://script.google.com> → **새 프로젝트**
2. `gas/Code.gs` 내용을 `Code.gs`에 붙여넣기
3. 프로젝트에 **HTML 파일**을 추가해 이름을 `app` 으로 하고, `gas/app.html` 내용을 붙여넣기
   - `gas/app.html`은 프론트 파일을 합친 결과물입니다. 프론트를 고쳤다면 아래로 다시 만듭니다.
     ```bash
     python3 tools/build-gas-html.py
     ```
4. (권장) `Code.gs` 맨 위 `CONFIG.TOKEN` 에 원하는 비밀 문자열을 넣습니다. → 앱 설정의 ‘공유 토큰’과 같은 값
5. **배포 → 새 배포 → 유형: 웹 앱**
   - 설명: `사단 통합 톡`
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자**
6. 나온 `https://script.google.com/macros/s/…/exec` 주소를 폰·PC 브라우저에서 엽니다.
   - 이 주소 자체가 앱입니다. 홈 화면에 추가하면 앱처럼 열립니다.
   - `app.html`을 넣지 않았다면 “app.html 파일이 없습니다” 안내가 나옵니다.

> GAS 단독 배포에서는 앱이 `google.script.run`으로 같은 스크립트를 호출하므로 CORS·URL 입력이 필요 없습니다.
> 다만 Apps Script HTML 서비스는 iframe 안에서 열리므로 **서비스 워커(오프라인 캐시)는 동작하지 않습니다.** 오프라인까지 원하면 방법 B를 쓰세요.

### 방법 B — GitHub Pages(화면) + Apps Script(백엔드)

1. 방법 A의 1~5단계로 Apps Script 웹앱을 배포하고 `/exec` 주소를 복사합니다.
   (이때 `app.html`은 없어도 됩니다. `Code.gs`만 있으면 됩니다.)
2. 이 폴더의 `index.html`, `styles.css`, `app.js`, `manifest.json`, `sw.js`, `demo/`, `icons/` 를 GitHub 저장소에 올리고 **Settings → Pages** 를 켭니다.
   - `gas/` 폴더는 올리지 않아도 됩니다(올려도 무방).
3. 배포된 Pages 주소를 엽니다 → 우측 상단 **⚙ 설정**
   - `Apps Script 웹앱 URL`: 1번의 `/exec` 주소
   - `공유 토큰`: `Code.gs`의 `CONFIG.TOKEN` 과 같은 값
   - **저장** → 자동으로 `ping` 확인 후 ‘시트 연결됨’으로 바뀝니다.
4. 폰에서 열고 **홈 화면에 추가**하면 PWA로 설치됩니다(Android Chrome: 설치 배너/메뉴, iPhone Safari: 공유 → 홈 화면에 추가).

### `AI 채팅방`(A시트 `ai채팅` 탭)

- A·B사단 대원이 시트 `ai채팅` 탭에 적는 대화가 그대로 말풍선으로 보입니다(상태 배지는 표시하지 않음).
- 방에 들어가면 전송 대상이 자동으로 `A사단 · ai채팅`이 되고, **다른 방으로 나가면 쓰던 대상으로 돌아갑니다.**
- 태그는 `@전체 · 태그 없음 · @Muse · @Muse-B · @부이 · @부이-B · @Instinct · @Pally`.
- 이 탭의 4번째 열 `관련`에는 `[지시]` 머리말을 붙이지 않습니다. 태그를 고르면 태그만, `태그 없음`이면 `관련`을 비우고 `내용`(C열)만 기록합니다.

### `🏢 사단 오피스` (2.5D 아이소메트릭 디오라마)

- 5번째 방. 들어가면 말풍선·입력창 대신 **등각(2:1)으로 그린 입체 오피스**가 펼쳐집니다.
- **공간 구성**: 따뜻한 우드 타일 바닥 + 입체 벽 2면(햇살 창문 3개 · 벽시계 · 화이트보드 `TEAM` · 책장 · 커피머신 · 자판기) 위에
  **사장실**(대형 원목 책상·금색 명패·안락의자·화분), **팀장실**(A-Muse·B-Muse 듀오 책상), **A사단 존 / B사단 존**(대원별 입체 책상·모니터·머그·서류·의자),
  **라운지**(소파 2개·커피 테이블·바닥 쿠션·스탠드), **탕비실**, **회의 테이블**, **새로 합류 벤치**가 있습니다.
- **동물 봉제인형 캐릭터**: 대원마다 고유 동물(라운 사장님=사자, A/B-Muse=고양이, 피클=수달, 부이=병아리, Instinct=여우, Pally·뀨=토끼, 키링=포메, Hark-B=올빼미)을
  위에서 빛을 받은 듯한 그라데이션·핑크 귀·볼터치·반짝이는 눈(깜빡임)으로 그렸고, 새로 합류한 대원은 이름 해시로 동물을 배정합니다.
- **상태는 자세와 위치로**: **30분 안 = 🔥 열일중**(앞발 타자 + 모니터 빛 + 말풍선 `열일중!`·`작성 중...`), **2시간 안 = 💻 작업함**(고개 끄덕임 + `작성 중…`),
  **그 밖 = ☕ 대기**(커피잔을 들고 살랑), **기록 없음 = 💤 휴식**(라운지 소파·쿠션으로 이동해 눈 감고 `Zzz`, 자기 책상은 빈 의자 + `자리 비움`).
- **오늘의 오피스 패널**: 전체·열일·활동·대기·휴식 카운트, 팀별 명단(클릭하면 그 자리로 화면이 이동하며 반짝이고 상세 시트가 열림), 최근 시트 활동 6건.
- **조작**: `+` · `−` · `↺ 100%`(전체 보기) 버튼, 마우스·터치 드래그 이동, 휠·핀치 확대(폰·태블릿 대응).
- **테마 3종**: `☀️ 데이라이트` · `🌸 벚꽃 라운지`(꽃잎) · `🌙 나이트 오피스`(별이 뜬 창문·은은한 조명). 고른 테마는 브라우저에 기억됩니다.
- **캐릭터/책상 클릭** → 하단 시트에 동물 아바타·이름·역할·상태·마지막 활동·최근 시트 기록 3건.
- **새 AI 비서는 자동으로 자리가 생깁니다**: 고정 명단에 없는 이름이 기록을 남기면 그 사단 존에, 탭만 있고 아직 글이 없는 이름은 앞쪽 `새로 합류` 벤치에 앉습니다. `(미상)`·문장이 잘못 들어간 작성자명은 제외합니다.
- 이름 표기 차이는 묶습니다: `Muse`/`Muse (A사단장)` → A-Muse, `Muse-B`/`Muse (B사단장)` → B-Muse, `피클 (A사단)` → 피클, `Pickle` → 피클, `뀨-B (Cue)` → 뀨-B.

### 사진·동영상·파일 첨부(`+`)

- 입력창 왼쪽 `+` → `🖼️ 사진 · 동영상`(`image/*,video/*`) 또는 `📎 파일`(모든 파일)을 고릅니다. PC에서는 채팅 화면에 끌어다 놓아도 됩니다.
- 고른 파일은 **입력창 위 대기 바**에 이미지 썸네일(6MB 이하) 또는 아이콘·파일명·용량으로 보이고, `×`로 하나씩 뺄 수 있습니다.
- 제한: **파일당 15MB · 한 번에 합계 20MB**. 넘으면 토스트로 알려 주고 붙이지 않습니다.
- **텍스트 없이 첨부만 있어도 전송**됩니다. 전송 순서는 ① 파일을 Drive 폴더 `사단 통합 톡 첨부파일`에 업로드(버튼이 업로드 중 표시로 바뀜) ② 본문 끝에 `📎 [파일명](Drive 주소)`를 붙여 ③ 시트에 기록.

- 말풍선에서는 이 줄이 **누를 수 있는 첨부 카드**(아이콘·파일명·`열기`)로 그려집니다.
- 탭에 `링크`·`첨부`·`증빙`·`참고`·`URL` 열이 있으면 그 열에도 첫 번째 첨부 주소를 함께 적습니다.

## 6. 알아 둘 점(한계)

- **실시간 푸시가 아닙니다.** 시트는 대원들이 각자 다른 앱에서 쓰고 있으므로, 앱은 일정 간격(또는 새로고침)으로 시트의 새 행을 읽어 말풍선으로 보여 줍니다. 지시도 시트에 기록되므로 대원들은 지금처럼 시트를 확인하면 됩니다.
- 앱 안에서 대원과 1:1로 대화하는 기능은 없습니다. **시트 기록이 곧 대화 로그**입니다.
- 데모 데이터는 실제 시트 최근 행을 **본문 900자로 줄인 스냅숏**입니다. `시트 N행` 링크는 실제 행을 가리킵니다.
- A사단 시트에는 탭이 123개 있습니다. 앱은 **주요 3탭(피클·라운 채팅·시트1)** 을 기본으로 보여 주고, 나머지 탭은 `⋯ → 탭` 또는 입력창의 탭 선택에서 검색해 볼 수 있습니다.
- 자동 새로고침은 화면이 보일 때만 돕니다(배터리·할당량 절약).
- 한 행의 본문은 4,000자까지만 읽습니다(`Code.gs`의 `MAX_BODY`). `부이-B`처럼 셀 하나가 아주 긴 탭도 폰에서 빠르게 열리도록 한 제한입니다. 전문은 `시트 N행` 링크로 봅니다.

## 10. 문제 해결

| 증상 | 확인 |
| --- | --- |
| ‘연결하지 못했습니다’ | `/exec` 주소인지(→ `/dev` 아님), 액세스 권한이 ‘모든 사용자’, 토큰 일치 여부 |
| 빈 화면 | 브라우저 콘솔 확인. `app.html` 배포 시 파일명이 `app`인지 |
| 새 기록이 안 보임 | 헤더 새로고침, 방 메뉴의 탭 선택이 다른 탭으로 되어 있지 않은지 |
| 아이폰에서 설치 메뉴가 없음 | Safari로 열고 공유 → ‘홈 화면에 추가’ (iOS는 설치 배너를 자동으로 띄우지 않음) |
| 업데이트가 반영 안 됨 | `sw.js`의 `VERSION` 올리기, 또는 사이트 데이터 지우기 |
